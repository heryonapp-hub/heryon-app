Exclusão de dados e backups

Solicitação de exclusão de dados — Heryon

Última atualização: 1º de novembro de 2026

Aplicativo: Heryon · Desenvolvedor: Bflict

O Heryon permite excluir dados locais e backups manuais armazenados no Google Drive. Veja abaixo o procedimento e como solicitar orientação. Não é preciso criar uma conta Heryon.

1. Excluir backups do Google Drive

  1. Abra o Heryon no seu dispositivo.
  2. Entre em Configurações → Conta.
  3. Conecte a Conta Google usada para armazenar os backups, caso ainda não esteja conectada.
  4. Abra Gerenciar backups.
  5. Use a opção de exclusão para remover os backups desejados ou todos os backups do aplicativo.

Dependendo das opções escolhidas durante o backup, os dados excluídos podem incluir preferências, histórico, textos manuais, PDFs, documentos e metadados técnicos necessários à restauração. Excluir um backup não remove automaticamente a cópia local dos documentos.

2. Excluir dados locais do aplicativo

Abra as Configurações do Android → Aplicativos → Heryon → Armazenamento e escolha a opção de limpar dados, ou desinstale o aplicativo. Isso remove os dados locais mantidos pelo Heryon, mas não apaga os backups manuais existentes na Conta Google. A disposição exata das opções pode variar conforme o aparelho.

3. Pedir orientação sobre exclusão de dados

Você pode solicitar ajuda para excluir seus dados relacionados ao Heryon pelo e-mail:

heryon.app@gmail.com

Assunto sugerido: Solicitação de exclusão de dados — Heryon

Descreva quais dados deseja excluir e se o problema é com dados locais ou backups. Não envie senhas, códigos de autenticação ou documentos pessoais desnecessários.

A Bflict poderá orientar a exclusão e tratar solicitações relacionadas a dados sob seu controle. Como os backups ficam na área privada associada à Conta Google do usuário, a Bflict não tem acesso direto para removê-los por conta própria; a exclusão precisa ser iniciada pelo usuário no Heryon com a conta correspondente.

4. Dados mantidos e prazo de armazenamento

Dados locais: permanecem no dispositivo até serem excluídos pelo usuário, pela limpeza dos dados do app ou pela desinstalação.

Backups no Google Drive: permanecem associados à Conta Google do usuário até serem excluídos por ele. O Heryon não mantém cópias desses backups em servidor próprio da Bflict.

Dados dos serviços Google ou de outros fornecedores externos: podem estar sujeitos às políticas e aos prazos de retenção desses fornecedores, fora do controle do Heryon.

Importante: excluir dados do Heryon não exclui nem desativa a Conta Google do usuário.

5. Política de Privacidade

Para saber mais sobre como o Heryon utiliza e protege dados, consulte a Política de Privacidade do Heryon.
