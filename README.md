## Sobre o Heryon

O Heryon é um aplicativo de leitura em voz para PDFs, documentos e textos manuais.  
Ele permite abrir conteúdos no dispositivo, ouvir textos em voz, ditar ideias por microfone, salvar textos manuais e usar backup manual opcional com Conta Google.
