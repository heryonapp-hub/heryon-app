1. eSpeak NG / espeak-ng-data

Licença: GPL-3.0-or-later

Uso no Heryon: dados de fonemização usados localmente/offline para auxiliar a conversão de texto em fala no mecanismo de leitura em voz.

Artefato usado: espeak-ng-data.tar.bz2 distribuído pelo projeto sherpa-onnx nos modelos TTS.

SHA-256 do tarball:

4135ccf82e1f40613491c0874d4945ae9e9c7840933d8e25a6f9e003d9ebf533

Hash agregado da pasta extraída:

c5454d3524594feac268215c19950cc993f2d61a722a0a030bb8523db89cf840

Origem upstream indicada pelo mantenedor do sherpa-onnx: projeto oficial eSpeak NG, gerado via processo de build/install.

git clone https://github.com/espeak-ng/espeak-ng
cd espeak-ng
mkdir build
cd build
cmake -DCMAKE_INSTALL_PREFIX=./install ..
make install

O diretório gerado pelo processo acima é:

install/share/espeak-ng-data/

Observação: o commit/tag exato do pacote espeak-ng-data.tar.bz2 distribuído com sherpa-onnx não foi informado pelo mantenedor.

Issue pública de diligência: k2-fsa/sherpa-onnx#3595

Texto da GPL-3.0: gpl-3.0.txt
