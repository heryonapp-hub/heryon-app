Esta Política de Privacidade explica como o Heryon trata dados, arquivos e permissões usados no aplicativo.

O Heryon é um aplicativo de leitura em voz para PDFs, documentos e textos manuais. O objetivo do app é permitir que o usuário abra conteúdos no dispositivo, escute esses conteúdos em voz, dite textos manuais e, opcionalmente, use backup manual com Conta Google.

1. Dados e arquivos usados pelo app

O Heryon pode acessar arquivos escolhidos pelo próprio usuário, como PDFs, documentos e textos, para permitir leitura em voz, visualização e continuidade de leitura.

Esses arquivos permanecem no dispositivo do usuário, exceto quando o próprio usuário decide usar o recurso de backup manual na nuvem.

O Heryon pode armazenar localmente informações necessárias para o funcionamento do app, como:

  • preferências de leitura;
  • configurações de voz;
  • histórico de leitura;
  • textos manuais salvos pelo usuário;
  • informações de sessão para continuar a leitura;
  • arquivos restaurados pelo backup manual, quando o usuário usa essa função.

2. Microfone e ditado por voz

O Heryon usa a permissão de microfone apenas quando o usuário aciona voluntariamente o recurso de ditado.

A finalidade do microfone é transformar a fala do usuário em texto manual. Depois disso, o usuário pode salvar esse texto no app e escutá-lo em voz.

O Heryon não usa o microfone em segundo plano para gravação contínua e não solicita acesso ao microfone para ler PDFs, documentos ou textos já existentes.

O Heryon não salva áudio bruto do microfone no código do app. O resultado do ditado é tratado como texto manual.

O reconhecimento de fala pode depender do serviço de reconhecimento disponível no Android do dispositivo, como serviços fornecidos pelo sistema ou por provedores instalados no aparelho. Nesses casos, o processamento da fala pode seguir as políticas do serviço de reconhecimento usado pelo dispositivo.

3. Conta Google e backup manual

O login com Conta Google é opcional.

Quando o usuário decide entrar com Google, o Heryon usa essa conta para permitir backup e restauração manual dos dados do app.

O backup manual pode incluir, conforme o funcionamento e opções disponíveis no app:

  • preferências e configurações;
  • histórico de leitura;
  • textos manuais;
  • arquivos PDF e documentos incluídos no backup.

O backup é iniciado pelo usuário. O Heryon não deve ser entendido como um serviço de sincronização automática contínua.

Os dados do backup são armazenados usando recursos do Google associados à conta do próprio usuário. O Heryon não mantém servidor próprio para armazenar esses backups.

4. Textos manuais

O usuário pode criar textos manuais digitando ou usando ditado por voz.

Esses textos podem ser salvos no app para leitura posterior em voz. Se o usuário usar o backup manual, textos manuais salvos podem ser incluídos no backup, conforme as opções disponíveis no app.

5. Dados que o Heryon não vende

O Heryon não vende dados pessoais do usuário.

O Heryon não utiliza os arquivos, textos, histórico ou dados de leitura do usuário para venda a anunciantes.

6. Compartilhamento de dados

O Heryon não compartilha arquivos ou textos do usuário com terceiros por iniciativa própria.

Alguns recursos dependem de serviços externos quando acionados pelo usuário, por exemplo:

  • login com Conta Google;
  • backup e restauração usando serviços Google;
  • reconhecimento de fala disponível no dispositivo Android.

Nesses casos, o uso desses serviços pode estar sujeito às políticas de privacidade dos respectivos provedores.

7. Segurança dos dados

O Heryon busca limitar o uso de dados ao necessário para as funções do app.

Dados locais ficam armazenados no dispositivo do usuário. Quando o usuário usa login Google ou backup manual, a comunicação com os serviços Google ocorre por mecanismos de autenticação e conexão segura fornecidos pela plataforma.

8. Exclusão de dados

O usuário pode excluir dados locais do Heryon apagando os dados do app nas configurações do Android ou desinstalando o aplicativo.

Quando houver backups manuais salvos na Conta Google, o usuário pode remover esses dados pelos recursos disponíveis no próprio app, quando presentes, ou pela própria conta/armazenamento Google.

9. Permissões usadas

O Heryon pode solicitar permissões conforme os recursos usados pelo usuário:

  • Microfone: usado apenas para o recurso de ditado por voz, quando o usuário inicia o ditado.
  • Internet: usada para login Google, backup/restauração manual e recursos que dependem de conexão.
  • Serviço em primeiro plano / reprodução de mídia: usado para manter a leitura em voz funcionando corretamente e exibir controles de reprodução enquanto o áudio está ativo.
  • Arquivos/documentos: usados apenas quando o usuário escolhe abrir, importar, visualizar, salvar ou restaurar arquivos no app.

10. Crianças

O Heryon não é direcionado especificamente a crianças. O app é voltado a usuários que desejam ler, ouvir, organizar ou ditar textos e documentos.

11. Alterações nesta política

Esta Política de Privacidade pode ser atualizada para refletir mudanças no aplicativo, em recursos, permissões ou exigências legais.

Quando houver alterações relevantes, a data de atualização no início deste documento será modificada.
